# Projeto ETL de Vendas

Projeto simples de Engenharia de Dados desenvolvido em Python utilizando ETL (Extract, Transform and Load).

## Objetivo

Realizar:

* ingestão de dados CSV;
* transformação e limpeza dos dados;
* carga em banco SQL;
* análises de vendas.

## Tecnologias utilizadas

* Python
* Pandas
* SQLite
* Google Colab
* SQL

## Pipeline

CSV → Transformação → SQLite → Análises

## Funcionalidades

* Leitura de CSV
* Tratamento de dados
* Criação de métricas
* Consultas SQL
* Visualização de dados

## Exemplo de ETL

### Extract

Leitura do CSV de vendas.

### Transform

* Conversão de datas
* Criação de coluna valor_total
* Criação de coluna mês

### Load

Carga dos dados em banco SQLite.
